## Project Description
This project is a personal portfolio website created to showcase my skills, projects, experience, and progress as a developer. It provides an overview of who I am, the technologies I have learned, the projects I have worked on, and the lessons and challenges I experienced during development.
The portfolio was built using HTML, CSS, and JavaScript and deployed using GitHub Pages. It is designed to be responsive, simple to navigate, and easy for visitors to explore my work.
